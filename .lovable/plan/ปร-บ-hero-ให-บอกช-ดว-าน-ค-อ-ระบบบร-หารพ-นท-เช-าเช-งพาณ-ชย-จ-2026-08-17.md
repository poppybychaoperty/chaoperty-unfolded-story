# ปรับ Hero ให้บอกชัดว่านี่คือ "ระบบบริหารพื้นที่เช่าเชิงพาณิชย์" + จัดกลุ่มระบบนิเวศเป็น 3 ชั้น

## 1. Hero — อธิบายให้เข้าใจใน 3 วินาที

แทนที่ประโยคยาว "ปล่อยเช่า → ทำสัญญาและเก็บค่าเช่า → งานซ่อมบำรุง → ลูกค้าหน้าร้านกลับมาซ้ำ..." ด้วยโครงสร้างใหม่:

- บรรทัดนิยาม (คำอธิบายตรง ๆ ว่ามันคืออะไร):  
"Commercial Property Management System and so much "more" (empathise the so much more part i.e. similar to   
**ทั้งระบบ underlining thing**) — ระบบบริหารพื้นที่เช่าเชิงพาณิชย์ครบวงจร สำหรับตลาด คอมมูนิตี้มอลล์ อาคารสำนักงาน และพื้นที่ให้เช่าทุกรูปแบบ ที่ตอบโจทย์คุณมากกว่า"
- ย่อหน้าสอง (สั้น เป็นประโยคคนพูด): บอกว่ารวมงานสัญญา–วางบิล–เก็บเงิน–งานซ่อม–ข้อมูลลูกค้าหน้าร้าน ไว้บนข้อมูลชุดเดียว ไม่ต้องคีย์ซ้ำ ไม่ต้องตามงานในไลน์
- ตัดคำโฆษณาลอย ๆ ("ขับเคลื่อนด้วย AI" ในแบดจ์) ให้เหลือข้อความที่เป็นข้อเท็จจริง

## 2. เซกชันระบบนิเวศ — แยกให้เห็นว่าอันไหน "หน้าบ้าน / หลังบ้าน / ลูกค้า"

ตอนนี้การ์ด 5 ระบบเรียงเป็นกริดเดียวกันหมด แยกกันไม่ออก จะจัดใหม่เป็น **3 แถวชั้นงาน** มีหัวข้อกำกับแต่ละชั้น:

```text
ชั้นที่ 1 · จัดการพื้นที่เช่า (Core / หน้าบ้าน–งานเจ้าของพื้นที่)
   Chaoperty (>200 ยูนิต)   dChao (<200 ยูนิต)   PopSpace (เช่าระยะสั้น/อีเวนต์)

ชั้นที่ 2 · งานหลังบ้าน (Operations)
   dWork — งานแจ้งซ่อม งานรูทีน ผู้รับเหมา คลังอะไหล่

ชั้นที่ 3 · ลูกค้าปลายทาง (CRM)
   Tamtam — เช็คอิน สะสมแต้ม โปรโมชั่นร้านค้า
```

- แต่ละชั้นมีหัวข้อ + คำอธิบายหนึ่งบรรทัดว่า "ใครใช้" (เจ้าของ/ผู้จัดการพื้นที่ · ทีมช่างและ รปภ. · ผู้เช่าและลูกค้าที่มาเดิน)
- เพิ่มป้าย "ใครใช้:" บนการ์ดแต่ละใบ แทน role สั้น ๆ ที่ตอนนี้กำกวม
- คงลิงก์ "ดูรายละเอียด" และการ์ด "ไม่แน่ใจว่าต้องเริ่มตรงไหน?" ไว้ (ย้ายไปท้ายเซกชัน)
- แถบ flow 4 ขั้นด้านบนคงไว้ แต่ผูกป้ายชั้นงานเข้ากับแต่ละขั้นให้เห็นว่าขั้นไหนใช้ระบบไหน

## 3. ลดความรู้สึก "AI generated"

- ตัดคำโปรยสไตล์การตลาดซ้ำ ๆ ให้เหลือประโยคเฉพาะเจาะจง ใช้ตัวเลข/ชื่อเรียกจริงในวงการ (นิติบุคคล มิเตอร์น้ำ–ไฟ ใบวางบิล ใบ 50 ทวิ)
- ลดการ์ดโค้งใหญ่/เงาฟุ้ง/hover ยกลอยทั้งกริด ให้เป็นเส้นคั่นและกรอบบางแบบเอกสารธุรกิจ
- ลดจำนวนไอคอนตกแต่ง เก็บเฉพาะที่สื่อความหมาย
- ใช้คำอธิบายที่มาจากงานจริงหน้างาน (เช่น "เก็บค่าเช่าแผงหน้างานด้วยเครื่องพิมพ์ใบเสร็จ") ที่มีอยู่แล้วในหน้าเพจ

## รายละเอียดทางเทคนิค

- แก้ `src/components/landing/hero.tsx`: พาดหัว/คำโปรย/แบดจ์
- แก้ `src/components/landing/ecosystem.tsx`: เพิ่มโครง `LAYERS` (core / operations / crm) แล้ว render เป็นกลุ่ม พร้อมหัวข้อชั้นและ "ใครใช้"
- ปรับสไตล์การ์ดให้เรียบขึ้น ใช้โทเคนสีเดิมใน `src/styles.css` ไม่เพิ่มสี hardcode
- อัปเดต meta description ใน `src/routes/index.tsx` ให้มีคำว่า "ระบบบริหารพื้นที่เช่าเชิงพาณิชย์ / Commercial Property Management"
- ไม่แตะข้อมูล ตัวเลข หรือรูปจริงที่มีอยู่
