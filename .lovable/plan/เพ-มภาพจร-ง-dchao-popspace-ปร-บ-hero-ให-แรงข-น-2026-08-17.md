# เพิ่มภาพจริง dChao/PopSpace + ปรับ Hero ให้แรงขึ้น

## 1. ภาพหน้าจอจริงของ dChao / Chaoperty (7 ภาพที่อัปโหลด)
ก่อนนำขึ้นเว็บ ต้องลบ/แทนข้อมูลที่เป็นความลับในภาพ:

- ชื่อผู้เช่าจริง (นางสาว ณิชกานต์ ฯลฯ), รหัสสัญญา LE1029xx, ชื่อผู้ใช้ "Hi yuyu", ชื่อพอร์ต "Viewmallmall / กาดลำพูนจตุจักร", ยอดเงินจริง (฿3,851,035, ฿4,325,792.72), เลขบัตร/QR
- วิธีทำ: วาดทับพื้นที่ข้อความด้วยสีพื้นเดียวกับพื้นหลัง แล้วเขียนข้อความสาธิตแทน (ชื่อสมมติ เช่น "คุณสมชาย ก.", รหัส LE100xxx, พอร์ต "Chaoperty Demo Mall", ตัวเลขปัดใหม่) ด้วยสคริปต์ Python/PIL + ฟอนต์ไทย แล้วอัปโหลดเป็น CDN asset
- QR code ในภาพสัญญาเช่า: เบลอทิ้ง

ภาพที่จะใช้: แดชบอร์ด dChao PMS (ChaCha AI), งบรายรับรายจ่าย, แดชบอร์ด Chaoperty (ผู้เช่า + กราฟ), หน้าบัญชี/วางบิล, รายงาน, ผังพื้นที่เช่า (สี ว่าง/เช่าอยู่), หน้าสัญญาผู้เช่า

## 2. PopSpace — ถ่ายภาพจากเว็บจริง
- ใช้ Playwright เปิด https://popspace-spot-finder.lovable.app/ ถ่าย 2–3 หน้าจอ (หน้าแรก/ค้นหาตลาด, ผังล็อก, จอง)
- ถ้ามีข้อมูลผู้ใช้จริงโผล่ ให้แก้แบบเดียวกับข้อ 1
- อัปโหลดเป็น asset แล้วแทนที่ mockup JSX ใน `product-popspace.tsx`

## 3. ปรับส่วน dChao
`product-dchao.tsx`: เปลี่ยนจาก mockup วาดเอง เป็นแกลเลอรีภาพจริง 4–6 ภาพ (แดชบอร์ด AI, ผังพื้นที่, บัญชี/วางบิล, รายงาน) พร้อมคำบรรยายสั้นใต้ภาพ ในสไตล์เดียวกับ dWork/Tamtam

## 4. Hero ใหม่ให้ "ในหน้า" มากขึ้น (แนว DoorLoop)
- หัวข้อใหญ่ขึ้นมาก (สูงสุด ~72px บนจอใหญ่) กระชับกว่าเดิม เช่น "จัดการพื้นที่เช่าทั้งระบบ ในที่เดียว"
- ซับเฮดสั้นลง 1–2 บรรทัด + CTA คู่ใหญ่ (ทดลองฟรี / ดูเดโม) + บรรทัดความน่าเชื่อถือ (คะแนนดาว, จำนวนพื้นที่ที่ดูแล)
- พื้นหลังเข้ม/มีสีแบรนด์เต็มความกว้าง ตัดกับส่วนถัดไป
- แทนที่การ์ด mockup ด้วย **ภาพแดชบอร์ด dChao จริง (ที่ลบข้อมูลลับแล้ว)** วางเอียงเล็กน้อย/เต็มความกว้างใต้ข้อความ
- แถบโลโก้ 4 ระบบ (dChao · dWork · Tamtam · PopSpace) ใต้ hero
- สถิติเด่นแบบ DoorLoop วางต่อทันที

## รายละเอียดทางเทคนิค
- สคริปต์แก้ภาพอยู่ใน /tmp เท่านั้น, ผลลัพธ์อัปโหลดผ่าน `lovable-assets create` → `src/assets/*.asset.json`
- ไม่คัดลอกไฟล์ภาพต้นฉบับเข้า repo
- แก้ไฟล์: `hero.tsx`, `product-dchao.tsx`, `product-popspace.tsx`, `stats.tsx` (ถ้าจำเป็น), `styles.css` (โทน hero เข้ม)
