# Chaoperty Ecosystem Landing Page

หน้า Landing เดียวจบ (ภาษาไทยเป็นหลัก) ที่เล่าภาพรวม "ระบบนิเวศจัดการพื้นที่เช่าเชิงพาณิชย์" ของ Chaoperty ครอบคลุมทั้งสามผลิตภัณฑ์ ตั้งแต่ปล่อยเช่า → เก็บเงิน → งานซ่อมบำรุงหลังบ้าน → CRM/สะสมแต้มลูกค้าปลายทาง

สไตล์: SaaS สว่างแบบ DoorLoop — โทนแบรนด์เหลือง/ดำของ Chaoperty, การ์ดโค้งมน, ตัวเลขพิสูจน์ผลใหญ่ๆ, ภาพจำลองหน้าจอผลิตภัณฑ์

## โครงหน้า (route `/`)

1. **Nav** — โลโก้ Chaoperty + ลิงก์เลื่อนภายในหน้า (ระบบนิเวศ, ผลิตภัณฑ์, ขั้นตอนการทำงาน, ราคา/ติดต่อ) + ปุ่ม "ทดลองใช้ฟรี"
2. **Hero** — พาดหัว "ระบบนิเวศจัดการพื้นที่เช่าครบวงจร ตั้งแต่สัญญาถึงลูกค้าหน้าร้าน" + ปุ่มหลัก "ทดลองใช้ฟรี" (ลิงก์ออกไปฟอร์มเดิม) + mockup แดชบอร์ด
3. **แถบตัวเลขพิสูจน์ผล** — 15 ปีพัฒนาซอฟต์แวร์ · 20,000 ยูนิต · 100+ โครงการ · ประหยัด ~20 ชม./สัปดาห์
4. **ปัญหาที่เจอทุกเดือน** — 3 การ์ด: ออกบิลทีละห้อง, งานซ่อมหายในไลน์, ไม่รู้จักลูกค้าที่มาใช้พื้นที่
5. **ระบบนิเวศเดียว 3 ส่วน** — ไดอะแกรม dChao (หน้าบ้าน/เช่า) → dWork (หลังบ้าน/ซ่อมบำรุง) → Tamtam (CRM/ลูกค้าปลายทาง) พร้อมเส้นเชื่อมการไหลของข้อมูล
6. **เจาะลึก dChao** — สัญญาเช่าครบวงจร, มิเตอร์น้ำ–ไฟ + CT/Surcharge, ตั้งหนี้–วางบิล–รับชำระ, พอร์ทัลผู้เช่า, หลายสกุลเงิน + FX, สัญญา 3 ภาษา, ผู้ช่วย ChaCha AI สรุปทุกเช้า + ภาพจำลองใบวางบิล
7. **เจาะลึก dWork** — งานรับแจ้ง, งานรูทีนอัตโนมัติ, งาน outsource, ใบอนุญาต/สัญญาแจ้งเตือนหมดอายุ, คลังอะไหล่, ภาษี/ค่าธรรมเนียม, เชื่อม LINE ด้วย AI, รายงานผู้บริหาร + ภาพจำลองบอร์ดงานวันนี้
8. **เจาะลึก Tamtam** — เช็คอินร้าน, อัปโหลดใบเสร็จ (20 บาท = 1 แต้ม), แลกของรางวัล, โปรโมชั่น/ข่าวสารร้านค้า, ชุมชนรูปเช็คอิน + ภาพจำลองหน้าจอมือถือ
9. **สายงานเชื่อมกันทั้งสตรีม** — ไทม์ไลน์ 5 ขั้น: ปล่อยเช่าพื้นที่ → ทำสัญญา/เก็บค่าเช่า → ผู้เช่าแจ้งซ่อม → ทีมช่างปิดงาน → ลูกค้าหน้าร้านสะสมแต้ม (ข้อมูลย้อนกลับสู่เจ้าของพื้นที่)
10. **เหมาะกับใคร** — ตลาด/แผงเช่า, คอมมูนิตี้มอลล์/พลาซ่า, อาคารสำนักงาน, อพาร์ตเมนต์/หอพัก, โกดัง/พื้นที่อุตสาหกรรม
11. **CTA ปิดท้าย + ฟุตเตอร์** — ปุ่มทดลองใช้ฟรี (ลิงก์ Google Form เดิม) และลิงก์ตรงไปแต่ละระบบ: dchao.chaoperty.com, dwork.chaoperty.com, tamtam.chaoperty.com

## รายละเอียดทางเทคนิค

- เขียนทับ `src/routes/index.tsx` (แทน placeholder) เป็นหน้าเดียว แยกเป็นคอมโพเนนต์ section ใต้ `src/components/landing/`
- Design tokens ใหม่ใน `src/styles.css` (oklch): เหลืองแบรนด์เป็น primary, พื้นหลังครีม/ขาว, ตัวหนังสือดำเข้ม, accent ต่อผลิตภัณฑ์ (dChao / dWork / Tamtam) — ไม่ใช้สี hardcode ในคอมโพเนนต์
- ฟอนต์ไทยที่รองรับเว็บ (เช่น IBM Plex Sans Thai / Noto Sans Thai) โหลดผ่าน `<link>` ใน `src/routes/__root.tsx`
- ภาพ mockup ผลิตภัณฑ์สร้างด้วย image generation เก็บใน `src/assets/` พร้อม alt ภาษาไทย
- SEO: `head()` เฉพาะของหน้าแรก — title/description/og/twitter เป็นภาษาไทยเกี่ยวกับ Chaoperty, H1 เดียว, semantic sections, JSON-LD แบบ Organization/SoftwareApplication
- ไม่มีแบ็กเอนด์: ปุ่ม CTA ทุกจุดลิงก์ออกไปฟอร์มทดลองใช้เดิมและซับโดเมนของแต่ละระบบ
- เนื้อหาทั้งหมดอ้างอิงจากข้อความจริงบนเว็บทั้งสี่แห่ง ไม่แต่งตัวเลขหรือรีวิวขึ้นใหม่
