# ปรับหน้าแลนดิ้ง: มาสคอตเด่นขึ้น + รูปจริง + โซเชียล

## 1. รื้อแถบ "โลโก้ 4 ระบบ + สถิติดำ" ที่ไม่ชอบ

ปัญหาปัจจุบัน: ใต้ hero มีแถวชื่อระบบลอยๆ ไม่มีบริบท ต่อด้วยบล็อกสถิติพื้นดำเหลืองที่ตัดกับโทนฟ้าสะอาดของ hero

เปลี่ยนเป็น:
- แถวระบบ → การ์ดแนวนอน 4 ใบ พื้นขาว ขอบมน มีมาสคอตของแต่ละระบบวางเด่น + ชื่อ + คำอธิบายสั้น + สีแบรนด์ประจำระบบ (ฟ้า / เหลือง / ม่วง / ม่วงเข้ม) กดแล้วเลื่อนไปยังส่วนของระบบนั้น
- บล็อกสถิติ → พื้นอ่อน (cream/ฟ้าอ่อน) ตัวเลขสีเข้ม มีเส้นคั่นบางๆ แทนพื้นดำ ให้ต่อเนื่องกับ hero

## 2. มาสคอตเด่นขึ้นในทุกส่วนของระบบ (ระดับกลาง)

แต่ละส่วน (dChao / dWork / Tamtam / PopSpace) เพิ่ม "การ์ดแนะนำระบบ" ด้านบน:
- มาสคอตขนาดใหญ่ (~96–128px) ลอยบนวงกลมสีแบรนด์อ่อน มีเงานุ่ม
- ข้างๆ เป็นชื่อระบบ + ประโยคเดียวว่าทำอะไร (สไตล์เดียวกับภาพ chacha ที่แนบมา แต่ไม่ล้นจนกลบเนื้อหา)
- มาสคอตซ้ำเล็กๆ เป็นจุดตกแต่งใน workflow timeline ตามขั้นตอนของระบบนั้น
- PopSpace ยังไม่มีมาสคอต — ใช้ wordmark บนวงกลมสีเดียวกันให้ดูเป็นชุดเดียวกัน

## 3. รูปจริง (คน อาคาร ตลาด ทีมงาน)

- สร้างส่วนใหม่ "ใช้งานจริงในโครงการทั่วไทย" — แกลเลอรีรูปจริงแบบ bento/มาโซนรี พร้อมคำบรรยายสั้น ใต้ส่วนระบบนิเวศ
- เพิ่มแถบรูปเล็กในส่วน "กลุ่มลูกค้า" ให้เห็นสถานที่จริงคู่กับแต่ละกลุ่ม
- ตอนนี้ยังไม่มีไฟล์รูปจริงในโปรเจ็กต์ (Facebook ดึงอัตโนมัติไม่ได้) → จะสร้างโครงพร้อมที่ว่างสำหรับรูปไว้ก่อน ใช้ภาพแทนชั่วคราวแบบเรียบ เมื่อคุณอัปโหลดรูป 6–12 รูปจากเพจ ผมจะสลับเข้าไปให้ทันที (ไม่ต้องแก้โครงอีก)

## 4. โซเชียล — ฝังวิดีโอ + การ์ดลิงก์

- ส่วน "ดูงานจริงของเรา": การ์ด 3 ใบ YouTube / TikTok / Facebook พร้อมไอคอนแบรนด์ คำอธิบายว่าดูอะไรได้ และลิงก์เปิดแท็บใหม่
- พื้นที่ฝังวิดีโอ YouTube (lazy-load ด้วย thumbnail กดแล้วค่อยโหลด player เพื่อไม่ให้หน้าหนัก) — เตรียมช่องไว้ 2 ตัว รอลิงก์วิดีโอจากคุณ ระหว่างนี้แสดงการ์ดลิงก์ไปช่องแทน
- เพิ่มไอคอนโซเชียลในเมนูบน (desktop) และในฟุตเตอร์

## รายละเอียดทางเทคนิค

- แก้: `stats.tsx`, `ecosystem.tsx`, `product-*.tsx`, `workflow.tsx`, `audience.tsx`, `site-nav.tsx`, `final-cta.tsx`
- ไฟล์ใหม่: `src/components/landing/social-proof.tsx` (แกลเลอรีรูปจริง), `src/components/landing/social-channels.tsx` (YouTube/TikTok/Facebook), `src/components/landing/product-intro.tsx` (การ์ดมาสคอต reusable)
- เพิ่มลิงก์โซเชียลใน `links.ts` และเพิ่ม `sameAs` ใน JSON-LD ของ Organization ใน `src/routes/index.tsx`
- รูปที่อัปโหลดจะขึ้น CDN ผ่าน lovable-assets และอ้างผ่าน `.asset.json` เหมือนรูปเดิม
- โทนสีทั้งหมดใช้ design token เดิมใน `styles.css` ไม่ฮาร์ดโค้ดสี
